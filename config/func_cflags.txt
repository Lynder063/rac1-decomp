# Extra compiler flags for single functions (tools/func_cflags.py splices
# them into their file's compiled assembly). One function per line:
#
#   func_XXXXXXXX  flags...
#
# -mno-split-addresses: retail reaches every global of the function
# through the assembler's `lui $at` macro, not a %hi/%lo split, while its
# neighbours in the same file use the split form. See docs/LEVERS.md.
# -fno-schedule-insns: no first scheduling pass (Lombyte builds some SDK
# units this way, e.g. sceSifInitIopHeap).
# -fno-sched-interblock: no instruction moved between the blocks of a loop.
# The scheduler treats a loop as one region only up to 100 insns, notes
# included; retail's build was past that limit for this function's loop and
# made none of the four moves ours makes at 81 (twenty more notes in the
# loop give retail's code with no flag, and so does -g, whose line notes
# count). The flag has the same effect for the one function.

func_L15_002F9FF8  -fno-force-mem
func_0023C960  -mno-split-addresses
